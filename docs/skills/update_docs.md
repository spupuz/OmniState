# Skill: update docs

**Description:** Updates project documentation, README files, and design docs to reflect
the current codebase state.

**When to run:** After significant UI/API changes to keep docs in sync with code.

## What This Skill Does

2. **Generates release notes** - Lists recent changes from git log
3. **Updates README** - Documents UI changes, API endpoints, and new features
4. **Creates skill docs** - Documents the skill itself
