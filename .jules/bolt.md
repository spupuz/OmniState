## 2023-10-27 - [Dictionary `.get()` method evaluates default arguments prematurely]
**Learning:** In Python, when using the `.get()` method on a dictionary with a default value that is a function call (e.g. `my_dict.get(key, expensive_func())`), the function `expensive_func()` is executed unconditionally, BEFORE `.get()` is even called. This means that if `.get()` hits a cache key, you are STILL running the expensive operation, completely defeating the purpose of the cache.
**Action:** Avoid calling functions as the default argument in `dict.get()`. If the default is an expensive operation, use `val = my_dict.get(key)` followed by `if val is None: val = expensive_func()`. Or, if the dictionary is guaranteed to have the key, just use normal bracket lookup `val = my_dict[key]`.
