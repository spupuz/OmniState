## YYYY-MM-DD - Avoid Mouse-Only Tooltips
**Learning:** Data values exposed exclusively through mouse-only tooltips (e.g., via the `title` attribute) are inaccessible to keyboard and touch-device users. Visually hidden `<span class="sr-only">` elements only solve part of the problem.
**Action:** Prioritize adding permanently visible text labels alongside visual representations to ensure universal accessibility and immediate scannability.
