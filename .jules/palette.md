## 2024-05-18 - Accessible Custom Comboboxes with Virtual Focus
**Learning:** When building custom comboboxes with virtual focus, ensure screen reader compatibility by setting `role="combobox"` on the input, linking it to the listbox via `aria-controls`, and dynamically synchronizing `aria-activedescendant` on the input with the `id` of the currently focused option while managing `aria-selected` states natively in JavaScript event handlers. Be careful to reference `e.target` instead of lexically scoped variables when updating attributes inside the input's event listeners to prevent runtime errors.
**Action:** Apply `role="combobox"`, `aria-autocomplete`, `aria-controls`, and `aria-expanded` to the input element. Use `role="listbox"` for the list and `role="option"` with explicit `id`s for options. Update `aria-activedescendant` and `aria-selected` dynamically in response to keyboard and mouse interactions without modifying actual DOM focus.
