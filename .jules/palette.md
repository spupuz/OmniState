## 2024-05-18 - Dynamically updating ARIA attributes in custom comboboxes
**Learning:** When building custom comboboxes with virtual focus (like a command palette), using `aria-activedescendant` on the input element ensures screen readers announce the currently focused option as the user navigates with the keyboard. Furthermore, we must dynamically update `aria-selected` to `"true"` on the newly focused option and `"false"` on the previously focused option, as standard `:hover` or `.active` CSS classes do not provide accessibility semantics.
**Action:** When implementing arrow key navigation for custom lists or comboboxes, always synchronize the input's `aria-activedescendant` with the ID of the visually highlighted option and manage the `aria-selected` state of the options natively in the keydown and mouseenter handlers.
