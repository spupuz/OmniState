## 2026-09-30 - Fix Path Traversal in export_memories_markdown
**Vulnerability:** A path traversal vulnerability existed in the `export_memories_markdown` function in `server/store.py`, allowing an attacker to export markdown files outside of the intended database directory by specifying a malicious `output_dir` (e.g., `../../../../tmp`).
**Learning:** This vulnerability existed because path validation was inconsistent across similar functions. While `export_memories` had logic to resolve paths and ensure they remained within the base directory, `export_memories_markdown` lacked this protection and simply concatenated the base path with user input.
**Prevention:** When accepting user-provided paths for file operations, always use `pathlib.Path.resolve(strict=False)` on both the target path and the allowed base directory. Verify that `str(resolved_target).startswith(str(resolved_base) + os.sep)` and `resolved_target != resolved_base` to ensure the file strictly resides within the intended directory. Ensure this validation is applied consistently across all similar functions.
