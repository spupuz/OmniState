About OmniState

What is OmniState?

OmniState is a persistent memory server for AI coding agents. It provides cross-project memory, task tracking, session snapshots, and GitHub PR health monitoring.

Features

  • Persistent memory across sessions
  • Project discovery & indexing
  • GitHub PR health tracking
  • Workspace support (group related projects)
  • Shared memory (cross-project context)
  • Session snapshots & handoffs
  • Supermemory integration (cloud-backed)
  • Backup & restore

Tech Stack

  • Python 3.12 + FastAPI
  • SQLite (WAL mode)
  • Tailwind CSS + Chart.js
  • Docker containerized
